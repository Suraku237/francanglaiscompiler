\section{Design Basis and UML Conventions}
\subsection{Implemented system and scope}
The source now contains the editable React frontend, FastAPI backend,
deterministic lexer/parser and CustomTkinter collector. They are implemented,
not proposed components. This document supersedes the old desktop-only SDD.
The local CSV is shared; there is no database server, trained predictor,
authenticated user model or public multi-tenant deployment.

Nine class views collectively cover \textbf{49 authored production classes}:
47 Python class declarations, the factory-generated lexer \texttt{Token}, and
the TypeScript \texttt{ApiError}. The machine-readable mapping is
\nolinkurl{docs/diagrams/class-coverage.json}. Test helpers, maintenance tools,
framework classes and erased TypeScript interfaces are outside that count.
The remaining views are 14 sequences, two states, one activity, one use case,
one component view and one deployment view.

\subsection{How to read the models}
\begin{itemize}
\item A hollow triangle points to a superclass. A filled diamond identifies
exclusive lifecycle ownership, used for the collector's optional recorder.
Plain directed associations represent stored references or nested values.
\item Target-end multiplicities express values held by one source instance.
A reverse \texttt{0..*} allows independent/shared DTO instances: nesting in
JSON does not establish exclusive Python object ownership. Inheritance and
module dependencies have no cardinalities.
\item Rectangles marked module/function/hook are not invented runtime classes.
External framework classes and repeated reference nodes are labelled explicitly.
Only selected fields and operations appear; inherited Pydantic validation and
serialization need not be repeated in every box.
\item Every shown synchronous call opens a receiver activation and has a
matching dashed reply ending it. Nested calls to the same participant open
nested boxes. Callers stay active while waiting. Actor boxes denote participation,
not CPU execution. Callback delivery is distinguished from GUI execution.
\item \texttt{alt}, \texttt{opt} and \texttt{loop} denote alternatives,
conditional interaction and repetition. Notes summarize omitted widget,
validation or low-level I/O steps; they are not messages without activations.
\item Activity diamonds have exclusive guards. State labels model logical
workflow or derived fields, not an imaginary implemented state enumeration.
Completing an entry activity is not shutting down the application.
\end{itemize}
The automated checker verifies class coverage and the explicit synchronous
call/reply activation convention used here. Local rendering and review are
still necessary; this checker is not a general-purpose UML theorem prover.

\section{Architecture and Deployment}
\subsection{Component dependencies}
Figure~\ref{fig:component} separates browser presentation, backend services,
compiler libraries, desktop presentation and local artifacts. Read dependency
arrows from the consumer toward the used responsibility. React request helpers
own cancellation and safe error presentation. Routes delegate validated
mutations, retrieval, imports and coursework work rather than treating the
provider as the compiler.

Both Python entry points call the same dataset module. The CSV symbol is a
file artifact, not a relational database. Coursework uses the compiler and
saved evidence; only explicit tutoring uses Gemini. Imports can produce
candidates but cannot implicitly append a row. Browser speech has its own
provider boundary, independent of Gemini and desktop recording.
The sixth browser workspace, Dictionary, reads versioned Markdown through
\nolinkurl{backend/dictionary.py}. These resources are not CSV corpus rows.
Retrieval can use either or both local sources; collection statistics and
compiler research continue to read only the saved CSV.

\subsection{Deployment topology}
Figure~\ref{fig:deployment} distinguishes the trusted workstation, execution

HTTP and the Vite API proxy. The alternative built mode serves the versioned

\texttt{Recorder}, \texttt{AudioError} and \texttt{EntryNotFoundError}.

\section{Data Design, Transactions and Review Rules}
\subsection{Storage schema and compatibility}
Canonical CSV order is \nolinkurl{id}, \nolinkurl{text}, \nolinkurl{entry_type},
\nolinkurl{french_gloss}, \nolinkurl{english_gloss}, \nolinkurl{category},
\nolinkurl{source_location}, \nolinkurl{notes}, \nolinkurl{audio_filename},
\nolinkurl{contributor}, \nolinkurl{timestamp}, \nolinkurl{language},
\nolinkurl{review_status}, \nolinkurl{lexical_category}.
The supported eleven-field prefix lacks review metadata; the ten-field legacy
format also lacks source location. Exact header order and row shape are checked.
Reads normalize legacy metadata in memory; a later mutation writes the
fourteen-field schema. Stored wording is not silently normalized for matching.

Language is Francanglais, Pidgin, mixed or unspecified. Approval is a local
review decision, not a verified identity or certificate. Eligible reviewed
Word annotations can affect lexical classification; mixed/unspecified or
conflicting labels are not silently promoted to trusted evidence. Desktop and
web forms choose unspecified/unreviewed for new drafts; the API's standalone
create DTO retains its documented Francanglais default when language is omitted.

\subsection{Transactional and identity boundaries}
A path-keyed reentrant \texttt{FileLock}, with ten-second timeout, protects
complete cooperative transactions. Every mutation writes a sibling temporary
file, flushes/fsyncs it and uses \texttt{os.replace}. It is not a direct append.
Pre-replacement failures preserve the old CSV. External manual writers and
semantic last-writer-wins editing are outside that guarantee.

Desktop IDs are ten UUID hexadecimal characters; API IDs are full UUID strings.
Desktop timestamps are local ISO seconds; API timestamps carry UTC offset.
IDs/timestamps survive editing. The file is not a database enforcing every
identity invariant: manually duplicated IDs can break GUI row identifiers and
must not be treated as supported concurrent editing.

\subsection{Reference vocabulary is not a research corpus}
The supplied \nolinkurl{dictionary/camfranglais.md} and
\nolinkurl{dictionary/extra_lexicon.md} contain 143 and 36 source rows,
respectively. Each row retains its headword, original English meaning,
topic, indicative etymological origin, source filename and line number.
All 179 rows are retained, including repeated headwords, identical duplicates
and distinct senses. This count is not a unique-word or collected-statement count.

The loader validates the three-column Markdown tables. Search normalizes
matching text only; displayed wording is unchanged. Explicit slash alternatives,
optional parenthesized wording such as \texttt{Na wa (oh)}, and terminal
question/exclamation-mark variants support lookup. IDs include the filename
and row line, not corpus UUIDs; editing source layout may change these IDs.
The two files are loaded afresh on requests, so a corrected source can be retried
without a stale-cache fallback.

The sources contain English meanings, not French translations or trusted
part-of-speech annotations. Etymological ``French''/``Pidgin'' labels do not
change the declared Francanglais reference language. No dictionary operation
inserts CSV rows, approves records, adjusts learner labels or inflates
coursework statistics. Export includes these files as implementation resources,
separate from corpus artifacts. The desktop collector remains CSV-based.
\viewtrace{FR-37; NFR-08, NFR-16}
{\nolinkurl{backend/dictionary.py}, \nolinkurl{frontend/src/Dictionary.tsx},
\nolinkurl{backend/coursework_export.py}}

\subsection{Audio and review ownership}
An entry references zero or one filename; a filename is not a foreign key or
exclusive object owner. Only files created for the current unsaved draft enter
its ownership set. Replacement/Clear/close remove those files with explicit
cleanup errors. A committed name is removed from draft ownership before reset.
Deleting a saved record retains its recording for deliberate separate cleanup.

The recorder distinguishes active capture, unfinished stopping and captured
samples awaiting publication. Save/attach/play guards prevent silent loss.
An approval snapshot must equal the current evidence values, including queued
GUI edits; editing evidence invalidates approval unless the exact revised
values are explicitly reviewed. These protections do not authenticate reviewers.

\section{Use Cases, Activity and State Models}

Figure~\ref{fig:use-case} groups contributor/maintainer and learner/reviewer

\subsection{One collection/save activity}
Figure~\ref{fig:activity-collect} reads from start to final node. Unfinished
capture and blank text terminate the attempt with the draft preserved.
Successful validation enters the locked mutation. A failed commit retains the
draft/audio; a successful one releases committed ownership and resets the form.
Cleanup and refresh failures are reported separately, never described as rollback.
The final node ends this attempt only. Desktop duplicates remain advisory.

\subsection{Logical entry and selected-editor states}
Figure~\ref{fig:state-entry} follows an unsaved draft through creation,
selection, edited values and confirmed deletion. Choice guards are exclusive.
Stale-ID/write failures return to a recoverable editor, not a fictitious saved
state. A selected editor may outlive a row removed by another process.
Successful deletion clears selection but leaves saved audio. These are
conceptual row/editor states; there is no corresponding enum in source.
\viewtrace{FR-02, FR-12, FR-18--FR-19, FR-22}{desktop save/edit/delete handlers}

\subsection{Audio readiness and retry states}
Figure~\ref{fig:state-audio} isolates the device lifecycle from row persistence.
Ready may already have an attachment. Failed start cleanup or failed stop
enters a retry state retaining usable handles/frames. Completed capture
attempts WAV publication; write failure retains the array for retry without
reopening the microphone. Clear is blocked during active recording, while
confirmed close attempts resource cleanup. A failed close keeps the window
available. A published WAV is still only staged until an entry is saved.

\section{Sequence Views: Detailed Interaction Explanations}
\subsection{Attachment and collection commit}
Figure~\ref{fig:sequence-collect} separates optional attachment from entry
creation. Copy failure preserves the previous attachment; success stages only
a generated name. Save first checks unfinished audio and trimmed text, then
passes a reviewed field snapshot to the dataset transaction. Only commit
success releases the audio reference from draft ownership and resets the form.
One subsequent snapshot drives all collection views. Refresh/cleanup errors
do not retroactively turn a committed save into a failed write.
\viewtrace{FR-02, FR-06, FR-09--FR-10, FR-17, FR-19}

\subsection{Search and cached selection}
Figure~\ref{fig:sequence-search} loads before replacing the visible tree.
A read error preserves the cache and editable draft. On success, case-folded
substring matching covers all stored values; the ID cache retains all rows,
including those hidden by the current filter. Selection uses this snapshot
without a second CSV read. A disappeared selected ID produces feedback while
preserving unsaved edits. An empty result is not a disguised storage failure.
\viewtrace{FR-11, FR-18; NFR-10}{\nolinkurl{App._refresh_browse_list}, \nolinkurl{App._on_browse_select}}

\subsection{Changed-field editing}
Figure~\ref{fig:sequence-edit} rejects absent selection/blank text, computes
changes against the loaded values and applies the exact-snapshot review rule.
The dataset layer finds the ID while locked and rejects stale updates without
rewriting. Expected failures preserve editor values. A successful update
synchronizes the local snapshot and refreshes views, reporting later refresh
failure independently. Unchanged identity, contributor, timestamp, whitespace
and audio metadata are preserved by the desktop editor.
\viewtrace{FR-06, FR-12, FR-18--FR-19, FR-22}
{\nolinkurl{App._save_browse_edit}, \nolinkurl{dataset.update_entry}}

\subsection{Confirmed deletion}
Figure~\ref{fig:sequence-delete} places the confirmation before any mutation.
No/dismissed leaves the row, selection and media untouched. Yes invokes the
locked deletion; missing IDs and storage failures cannot produce a success
message. Only a committed deletion clears selection and refreshes views.
The old saved recording is retained. Atomic replacement is not an undo system,
and confirmation is not authorization.
\viewtrace{FR-12, FR-18--FR-19}{\nolinkurl{App._delete_browse_entry}, \nolinkurl{dataset.delete_entry}}

\subsection{Recording, callback delivery and publication}
Figure~\ref{fig:sequence-record} first stops in-process playback, then opens
mono 44,100 Hz capture. Failed startup restores a truthful inactive state;
failed closure retains its handle for retry. Callback calls execute on the
device thread between GUI events and copy frames only while recording.
Stop returns samples, no samples or an explicit error. No samples preserve
any old attachment. WAV-write failure retains captured samples; retrying
publication does not start another recording. Save remains blocked while
capture work is unfinished. Physical audibility is a separate acceptance gate.
\viewtrace{FR-08, FR-10, FR-19; NFR-05}
{\nolinkurl{Recorder.start}, \nolinkurl{Recorder.stop}, \nolinkurl{App._save_captured_audio}}

\subsection{Playback and external fallback}
Figure~\ref{fig:sequence-playback} requires a filename and finished capture.
Missing files return failure. Available libraries read/play audio; an unavailable
or failed library path may launch the OS default player. The return value means
that a request was accepted, not that sound was heard to completion.
The GUI reports rejection or expected audio errors. In-process playback can
be stopped during cleanup; the lifetime of an externally launched player is
not controlled. No CSV mutation occurs.
\viewtrace{FR-13; NFR-03}{\nolinkurl{audio_utils.play_audio}, \nolinkurl{App._play_audio_filename}}

\subsection{Statistics from one snapshot}
Figure~\ref{fig:sequence-stats} replaces the old three-read design. A successful
read supplies a total and distributions by type, topic, language and review; batch refresh
passes the same rows to other views. Read failure leaves prior bars intact.
Each group sorts counts descending, uses a safe denominator and handles an
empty corpus explicitly. The recorded benchmark measures these actual active
handlers plus Tk idle rendering, not an isolated count helper.
\viewtrace{FR-14, FR-17; NFR-10}{\nolinkurl{App._refresh_stats}, \nolinkurl{App._refresh_views}}

\subsection{Shared CSV transaction}
Figure~\ref{fig:sequence-storage} expands the common persistence boundary.
Lock acquisition can time out before mutation. Within a successful acquisition,
the same reentrant lock supports nested reads, ID/duplicate checks and mutation.
Only completely written/fsynced sibling files reach atomic replacement.
The finally path removes an incomplete sibling and context-manager exit releases
the lock. Missing update/delete IDs never become successful rewrites.
Lock activations show acquire/release execution, not the whole ownership interval.
\viewtrace{FR-01, FR-06, FR-19, FR-25; NFR-11}{\nolinkurl{data_collector/dataset.py}, \nolinkurl{backend/collection.py}}

\subsection{Local-source translation}
Figure~\ref{fig:sequence-translation} shows explicit submission, reviewed
retrieval and three outcome paths. An unambiguous full-entry alignment returns
local wording without tone synthesis. Otherwise enabled AI may receive only
selected evidence; disabled AI produces actionable 422 guidance. Storage
failure does not fall through to a cloud request. Successful text is analyzed
locally and labelled with origin/model/evidence/coverage.
Cancellation prevents stale display, not guaranteed rollback of provider work.
Collection and dictionary use have independent switches, enabled by default.
Reference aliases participate in full-entry matching; English definitions
are not split into invented bilingual pairs. Distinct full-entry target meanings
remain ambiguous, even across the collection/reference boundary. Identical
targets can share source evidence. Missing dictionary French meanings cannot
veto a valid approved French alignment. Local results distinguish
\texttt{dataset}, \texttt{dictionary} and \texttt{local\_sources}; AI results
retain their AI designation, including \texttt{ai\_with\_sources}.
\viewtrace{FR-23--FR-24, FR-29, FR-35}{\nolinkurl{backend/main.py}, \nolinkurl{backend/grounding.py}}

\subsection{Chat history and provider boundaries}
Figure~\ref{fig:sequence-chat} uses only completed successful exchanges for
bounded history. Optional retrieval uses whitelisted evidence. Missing keys
fail before a network request; configured requests have a total deadline and
at most one bounded retry for an initial 503. Safe errors distinguish quota,
transport, timeout, blocked/truncated output and invalid content.
Only a current successful result appends a user/assistant pair. Failed turns
retain the draft. Clearing browser history does not erase provider-retained data.
The provider service rechecks each evidence source against its own switch;
turning collection use off must not strip enabled reference evidence, and
turning dictionary use off must exclude it. Citation metadata is separate from
private collection provenance. A reference is never described as approved fieldwork.

\subsection{Read-only dictionary lookup and handoff}
Figure~\ref{fig:sequence-dictionary} shows a debounced, cancellable search,

\subsection{Import preview, suggestions and explicit saving}
Figure~\ref{fig:sequence-imports} separates three actions. Preview validates a
bounded upload and extracts supported documents locally. Media/OCR requiring
cloud work must have explicit consent. A second action can request candidate
suggestions; validated candidates remain unreviewed exact source quotations.
Only an existing candidate deliberately opened, reviewed and saved reaches
collection mutation. Translate/assistant handoff fills a draft without submitting.
Original imports are not retained as managed collection files. A failed preview
does not authorize an automatic candidate save.

\subsection{Validation, errors and bounded work}
JSON request models reject extra fields and invalid lengths/values. PATCH
rejects null/empty updates. Relevant failures include 400 invalid import/consent,
404 missing entry/image, 409 duplicate conflict, 413 oversized input, 415
unsupported formats, 422 validation/grammar/coverage problems, 429 quota,
500 local storage failure, 502 invalid provider output, 503 busy/unconfigured
service and 504 provider timeout. Not every route emits every code; safe detail
messages remain actionable without returning secret-bearing provider bodies.

Imports are limited to 12 MiB, 40 PDF pages, 40,000 extracted characters and
4,000-character segments. Corpus analysis bounds 500 entries, 100,000 total
text characters and 4,000 per entry. Grammar input is bounded to 12,000
characters with additional expansion/snapshot/parse guards. Screenshots are
limited to six, 2 MiB and twelve megapixels each; accepted images are re-encoded.
The client also guards pending/listening/blank states but is not the only
validation boundary.

An aborted or timed-out mutation may already have committed. The frontend
preserves drafts and prompts refresh rather than promising rollback or blindly
duplicating a request. A reported local approval or readiness flag is never an
authenticated permission, independent research verification or grade.

\subsection{Backup, verify and restore procedure}
Close the collector/API and finish uploads/recordings before a snapshot.
The snapshot CLI copies CSV bytes, managed audio including unreferenced files,
saved profile and screenshots into a new destination with a SHA-256 manifest.
Keys, locks and incomplete temporary files are excluded. Missing/corrupt media,
unsafe paths, links and detected concurrent changes fail explicitly.

Verify before restoring, and restore only into another new directory.
Inspect restored rows/media before deliberately copying verified data back
with all applications stopped; copy CSV last. Never overwrite the live
collection directly through the restore tool. Protect backups as personal
research material. Checksums establish integrity, not authentic provenance
or permission to share.

\subsection{Remaining human and operational gates}
The group must supply genuine 10--15 manually transcribed statements across
the ten topics, known meanings/provenance/permission, the other two names and
matricules, and actual individual contributions. It must review classifications,
justify grammar against that corpus, interpret outcomes, provide genuine
screenshots and finish the separate 25--30-page research report and rehearsed
presentation. No synthetic test fixture is fieldwork.

Physical recording/playback, real mobile/assistive-technology use, authorized
live-provider trials, the original reference-machine benchmark and group
acceptance remain explicit gates. A trained unseen-word predictor is deferred.
These boundaries remain visible in the SRS product/sprint backlogs.
